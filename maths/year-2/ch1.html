🧮 1.1 Simplifying Expressions
Expression: terms joined by + or −. In 2x² + 3x − 4: three terms, variable x, coefficients 2 and 3, constant −4.
💡 Terms are shopping items: you can only add apples to apples, never apples to oranges.
Like terms have the same letters with the same powers: 2x² and 4x², 5x and 3x. Only like terms may be added or subtracted.
🔧 Method: simplify
  1. Spot like terms. The sign in front belongs to the term.
  2. Group them.
  3. Add/subtract the coefficients.
📘 Simplify 2x² − 3x − 7 − x² − 5x + 3
2x² − x² − 3x − 5x − 7 + 3group like terms
x² − 8x − 42x² − x² = 1x² = x²
⚠️ Common mistake: x and x² are not like terms, and neither are 3xy and 3x. Don’t merge them.

🔢 1.3 Evaluating Expressions
Evaluate: substitute the numbers for the letters, then work it out. Put each substituted number in brackets.
💡 Letters are blanks. Fill them in with brackets so the signs can’t escape.
🔧 Method: evaluate
  1. Substitute, with brackets: x → (3).
  2. Powers first (square before you multiply).
  3. × and ÷ before + and −. Anything × 0 = 0.

⚠️ Common mistake: (−2)² = +4, not −4. Always bracket a negative before squaring. Also give units (cm²) for areas.
⚖️ 1.4 Solving Linear Equations
Solve an equation: find the value of the variable that makes both sides equal. Whatever you do to one side, do the same to the other.
💡 A balanced scale: add or remove the same weight on both sides and it stays level.
🔧 Method: solve
  1. Remove brackets.
  2. Collect x-terms on one side (subtract the smaller).
  3. Move numbers to the other side.
  4. Divide by the coefficient of x.
  5. Check by substituting back.
📘 Solve 3(2x − 6) = 2(2x + 1)
6x − 18 = 4x + 2remove brackets
2x − 18 = 2− 4x each side
2x = 20+ 18 each side
x = 10÷ 2
⚠️ Common mistake: moving a term across without changing its sign. “+18 to the other side” becomes −18 – or, better, add 18 to both sides.

➗ 1.6 Algebraic Division
Array method: the grid used to multiply brackets, run backwards. The divisor goes down the side and the answer builds along the top.
💡 Multiplying fills the boxes from the answer. Dividing starts from the boxes and finds the answer.
🔧 Method: (x² + x − 12) ÷ (x + 4)
  1. Put the first term x² in box 1. Divide by x → x goes on top.
  2. x × (+4) = 4x goes in box 2.
  3. Box 2 + box 3 must make the middle term: x − 4x = −3x in box 3. −3x ÷ x → −3 on top.
  4. Check: (+4)(−3) = −12 ✓. Answer: x − 3
x−3
xx²−3x
+44x−12
Missing power: if a power is missing, write it with a zero coefficient before dividing. E.g. 4x³ − 13x − 6 becomes 4x³ + 0x² − 13x − 6. Dividing by (x − 2) gives 4x² + 8x + 3.
⚠️ Common mistake: the divisor (x − 2) goes into the grid as −2, not +2. Always check by multiplying back.
📏 1.7 Plotting Numbers on the Number Line
SetMeaningOn the number line
ℕ natural1, 2, 3, 4 …separate dots, arrow = continues
ℤ integers… −2, −1, 0, 1, 2 …separate dots
ℝ realall numbers on the line (fractions, decimals, √5, π)a heavy line – it “fills” the line
Inequality signs: > greater than · < less than · ≥ greater than or equal to · ≤ less than or equal to. An equation (x + 3 = 7) has equal sides; an inequality (x + 3 > 7) does not.
🧩 Remember it: ● closed circle = counted in (≥ ≤) · ○ open circle = out (> <)

x ≥ 4, x ∈ ℕ → 4, 5, 6, 7 …

x > −2, x ∈ ℤ → −1, 0, 1, 2 … (−2 itself is not included)

x ≥ 3, x ∈ ℝ → closed circle, heavy line to the right

x < −2, x ∈ ℝ → open circle, heavy line to the left

−3 ≤ x < 2, x ∈ ℝ → closed at −3, open at 2 (combined inequality)

⚠️ Common mistake: ℕ starts at 1, not 0. And for ℤ / ℕ use dots, for ℝ use a line.
⚖️ 1.8 Solving Inequalities
Do this to both sidesSignTest: 6 > 4
add or subtract the same numberstays6 + 4 > 4 + 4 ✓
multiply or divide by a positivestays6 × 3 > 4 × 3 ✓ (18 > 12)
multiply or divide by a negativereverses6 × (−2) < 4 × (−2) ✓ (−12 < −8)
🧩 Remember it: negative flips the sign. On the number line, −12 is left of −8, so the order turns round.
🔧 Method: solve an inequality
  1. Solve like an equation.
  2. Negative multiply/divide? → flip the sign.
  3. Graph in the right set: dots for ℕ ℤ, line for ℝ.
📘 Solve 4 − 3x > −5, x ∈ ℤ
−3x > −9− 4 each side
x < 3÷ (−3) → reverse the sign
x = 2, 1, 0, −1 …integers less than 3
⚠️ Common mistake: forgetting to flip when dividing by a negative. Check by trying one value from your answer in the original inequality.

❓ Quick Quiz

Which pair are like terms?

  1. 3x² and 3x
  2. 5xy and 5x
  3. 4a²b and 2a²b
  4. 2x and 2x²
Like terms need the same letters and the same powers. 4a²b and 2a²b match exactly; the others differ in a power or a letter.

2a²b × ab = ?

  1. 2a²b²
  2. 2a³b²
  3. 2a⁴b
  4. 3a³b²
Numbers: 2 × 1 = 2. Letters: a²×a = a³ (add indices), b×b = b². Answer 2a³b².

−4(5a − 2) = ?

  1. −20a − 8
  2. −20a + 8
  3. 20a + 8
  4. −20a − 2
−4 × 5a = −20a and −4 × (−2) = +8. The minus changes both signs.

(2x − 3)(3x + 4) = ?

  1. 6x² − 12
  2. 6x² + x − 12
  3. 6x² − x − 12
  4. 5x² − x − 12
Grid: 6x², −9x, +8x, −12. Middle terms: −9x + 8x = −x.

If x = −3, what is x²?

  1. −9
  2. 9
  3. −6
  4. 6
(−3)² = (−3) × (−3) = +9. Negative × negative is positive; bracket negatives before squaring.

Solve 3x − 5 = 16.

  1. x = 11/3
  2. x = 7
  3. x = 5
  4. x = 21
Add 5 to both sides: 3x = 21. Divide by 3: x = 7. (11/3 comes from subtracting 5 by mistake; 21 forgets to divide.)

Solve 5x − 4 = 4x + 7.

  1. x = 3
  2. x = 11
  3. x = −11
  4. x = 7
Subtract 4x from both sides: x − 4 = 7. Add 4: x = 11.

x is the first of three consecutive numbers with sum 168. Which equation?

  1. 3x = 168
  2. x + (x + 1) + (x + 2) = 168
  3. x + 2x + 3x = 168
  4. x + (x + 2) + (x + 4) = 168
Consecutive numbers go up by 1: x, x + 1, x + 2. So 3x + 3 = 168 and x = 55.

(x² + x − 12) ÷ (x + 4) = ?

  1. x − 3
  2. x + 3
  3. x − 4
  4. x + 8
Check by multiplying back: (x + 4)(x − 3) = x² + x − 12 ✓.

Before dividing 4x³ − 13x − 6 by (x − 2), what must you do?

  1. Rewrite it as 4x³ + 0x² − 13x − 6
  2. Change it to 4x³ + 13x − 6
  3. Divide −13x by x first
  4. Drop the x³ term
The x² term is missing, so write it as 0x². It keeps the boxes in the grid lined up.

List the values for x > −2, x ∈ ℤ.

  1. −2, −1, 0, 1 …
  2. −1, 0, 1, 2 …
  3. 1, 2, 3 …
  4. … −4, −3
> excludes −2, so the first integer is −1. They continue to the right.

Which graph shows x < −2, x ∈ ℝ?

  1. Closed circle at −2, heavy line to the right
  2. Open circle at −2, heavy line to the left
  3. Open circle at −2, dots at −3, −4, −5 …
  4. Closed circle at −2, heavy line to the left
< = open circle (−2 not included); “less than” = to the left; ℝ = a heavy line, not dots.

6 > 4. Multiply both sides by −2. Which is true?

  1. −12 > −8
  2. −12 < −8
  3. 12 < 8
  4. −12 = −8
6 × (−2) = −12 and 4 × (−2) = −8. −12 is left of −8, so the sign reverses to <.
