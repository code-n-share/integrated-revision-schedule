🔑 2.1 Factorising with Common Factors
Factors divide exactly into a number: 9 and 5 are factors of 45. The HCF is the biggest factor two terms share.
💡 Factorising is “un-expanding”: pull the shared piece out of the front and leave the rest in brackets.
Find the HCF ofNumbersLettersHCF

🔧 Method: factorise with the HCF
  1. Find the HCF of every term. Write it outside the bracket.
  2. Divide each term by it. Write the answers inside.
  3. Check: expand the bracket. You must get the original back.
📘 Factorise 6a²b − 8ab² + 4ab
HCF = 2abnumbers 2 · letters a, b
6a²b ÷ 2ab = 3a · 8ab² ÷ 2ab = 4b · 4ab ÷ 2ab = 2divide each term
2ab(3a − 4b + 2)check: expand ✓
📘 Factorise −3ax − 6ay (negative first term)
HCF = −3atake out the minus too
−3a(x + 2y)−3ax ÷ −3a = x · −6ay ÷ −3a = +2y
⚠️ Common mistake: if a whole term is the HCF, 1 is left behind, not 0: 3ab + 3a = 3a(b + 1). And “factorise fully” means include all the number and letter factors.
🔗 2.2 Factorising by Grouping Terms
Grouping: a four-term expression with no overall common factor can be split into two pairs. Factorise each pair; the brackets must now be the same, so take that bracket out.
💡 Like pairing socks first, then bundling the pairs: two small jobs, then one big one.
🔧 Method: grouping
  1. Split into two pairs (re-order the terms if you need to).
  2. Take the HCF out of each pair.
  3. Both brackets match? Take the common bracket out front.
  4. Check by expanding.

📘 Re-order first: factorise 6x² + 2a − 3ax − 4x

🧩 Remember it: “Pair, pull, bracket.” Pair the terms, pull out each HCF, bracket the match.
⚠️ Common mistake: brackets that nearly match, like (3a − b) and (b − 3a). Take out a minus from the pair to make them identical. Also, a pair like −(x − 2y) has an invisible 1: 2a(x − 2y) − (x − 2y) = (x − 2y)(2a − 1).
🟦 2.3 Difference of Two Squares
Perfect squares come from squaring: 1, 4, 9, 16, 25 … and in algebra 4x² = (2x)², 9y² = (3y)². An expression of the form one square − another square is the difference of two squares (DOTS).
💡 In (x + y)(x − y) the middle terms +xy and −xy cancel, which leaves only x² − y².
x² − y² = (x + y)(x − y)

In words: (first)² − (second)² = (first + second)(first − second)

🔧 Method: DOTS
  1. Take out any common factor first.
  2. Square-root each term: 9x² → 3x, 4 → 2.
  3. Write (first + second)(first − second).
📘 Factorise (i) 25a² − 81b² (ii) 12x² − 75y²
(i) (5a)² − (9b)²square roots
(5a + 9b)(5a − 9b)
(ii) 3(4x² − 25y²)HCF 3 first
3(2x + 5y)(2x − 5y)(2x)² − (5y)²
📘 Shortcut: work out 51² − 49² without a calculator
(51 − 49)(51 + 49)DOTS backwards
2 × 100 = 200
⚠️ Common mistake: DOTS needs a minus: x² + 9 (a sum) can’t be factorised this way. And always look for an HCF first: 3x² − 27y² → take out 3 to get 3(x + 3y)(x − 3y).
📐 2.4 Factorising Quadratic Expressions
Quadratic expression: ax² + bx + c where a, b, c are numbers. The highest power of x is 2. With 3 terms it is a quadratic trinomial. Factorising is the array method in reverse: (x + 5)(x + 2) = x² + 7x + 10.
💡 You are finding the two brackets that were multiplied to make it.
🔧 Method: x² + bx + c (when a = 1)
  1. Find two numbers that multiply to c and add to b.
  2. Write (x + first)(x + second), with their signs.
  3. Check: expand.
Last term (c)Middle term (b)BracketsExample
positivepositive(x + p)(x + q)x² + 7x + 10 = (x + 5)(x + 2)
positivenegative(x − p)(x − q)x² − 8x + 15 = (x − 3)(x − 5)
negativeeither(x + p)(x − q), different signsx² − 4x − 12 = (x − 6)(x + 2)
🧩 Remember it: multiply to the end, add to the middle. When the last term is negative, the bigger number takes the sign of the middle term.
🔧 Method: ax² + bx + c (when a > 1) – split the middle term
  1. Multiply a × c.
  2. List the pairs that make a × c. Pick the pair that adds to b (mind the signs).
  3. Split the middle term using that pair.
  4. Group in pairs (Section 2.2) and take out the common bracket.

⚠️ Common mistake: picking a pair that multiplies right but adds wrong. Test both: product = a × c, sum = b. Always expand your answer to check the middle term.
➗ 2.5 Using Factors to Simplify Algebraic Fractions
Simplify a fraction by dividing the top and bottom by a common factor: 1015 = 23. In algebra, factorise top and bottom first, then cancel the common factors.
💡 You can only cancel things that are multiplied, never things that are added.
🔧 Method: simplify an algebraic fraction
  1. Factorise the top.
  2. Factorise the bottom.
  3. Cancel each matching factor (bracket) top and bottom.
  4. Write what is left. If everything cancels on top, a 1 is left.
📘 Simplify 3x² − 5x − 2x − 2
(3x + 1)(x − 2) ÷ (x − 2)factorise the top
3x + 1cancel (x − 2)
📘 Simplify x² − 4x + 2
(x + 2)(x − 2) ÷ (x + 2)DOTS on top
x − 2cancel (x + 2)
⚠️ Common mistake: cancelling terms, not factors: x + 66 is not x + 1. Also 5 − xx − 5 = −1 (the top is −1 × the bottom), not 1.

❓ Quick Quiz

What is the HCF of 3xy and 12x²?

  1. 3x
  2. 12x
  3. 3xy
  4. 36x²y
Numbers: HCF of 3 and 12 is 3. Letters both terms share: x (only one has y). So 3x. (12x takes the bigger number; 3xy includes y, which 12x² doesn’t have.)

Factorise −3ax − 6ay.

  1. −3a(x − 2y)
  2. −3a(x + 2y)
  3. 3a(x + 2y)
  4. −3a(x + 2)
Take out −3a: −3ax ÷ −3a = x and −6ay ÷ −3a = +2y. Expanding −3a(x + 2y) gives back −3ax − 6ay. Option 3 gives +3ax + 6ay; option 4 loses the y.

Factorise 2a(x + y) + 3(x + y).

  1. (x + y)(2a − 3)
  2. 6a(x + y)
  3. (x + y)(2a + 3)
  4. (2a + 3)(x − y)
(x + y) is common to both parts, so take it out: (x + y)(2a + 3). Don’t multiply the 2a and 3 together.

Factorise ab + 5b + 3a + 15.

  1. (a + 5)(b + 3)
  2. (a + 3)(b + 5)
  3. (a + 5)(b − 3)
  4. (a − 5)(b − 3)
b(a + 5) + 3(a + 5) = (a + 5)(b + 3). Expand (a + 3)(b + 5) = ab + 5a + 3b + 15 – the middle terms are swapped, so it is wrong.

Which expression is a difference of two squares?

  1. x² + 16
  2. 4x² − 9
  3. x² − 6x
  4. 2x² − 9
4x² = (2x)² and 9 = 3², with a minus between: (2x)² − 3². x² + 16 is a sum; x² − 6x has no square second term; 2x² is not a perfect square.

Factorise 4x² − y².

  1. (4x + y)(4x − y)
  2. (2x − y)²
  3. (2x + y)(2x − y)
  4. (2x + y)²
√(4x²) = 2x, not 4x. So (2x + y)(2x − y). The middle terms +2xy and −2xy cancel – squared brackets would not.

Use DOTS to work out 96² − 4².

  1. 9212
  2. 9200
  3. 92
  4. 9232
(96 − 4)(96 + 4) = 92 × 100 = 9200. (9212 treats 4² as 4; 92 forgets the sum factor.)

Factorise x² − 7x + 12.

  1. (x − 3)(x − 4)
  2. (x + 3)(x + 4)
  3. (x − 2)(x − 6)
  4. (x − 3)(x + 4)
Pair: multiply to +12, add to −7 → −3 and −4. (x + 3)(x + 4) has the wrong signs (sum +7); (x − 2)(x − 6) multiplies to 12 but adds to −8.

To factorise 6x² + 7x − 5, which pair splits the middle term?

  1. −10 and 3
  2. 6 and −5
  3. 10 and −3
  4. 15 and −2
a × c = 6 × (−5) = −30. We need a pair that multiplies to −30 and adds to +7: 10 and −3. (−10, 3 add to −7; 6, −5 add to 1; 15, −2 add to 13.) Then 6x² + 10x − 3x − 5 = (3x + 5)(2x − 1).

Factorise 2x² − 7x + 3.

  1. (2x − 1)(x − 3)
  2. (2x + 1)(x + 3)
  3. (2x − 3)(x − 1)
  4. (2x − 1)(x + 3)
a × c = 6; pair that adds to −7: −1 and −6. 2x² − 6x − x + 3 = 2x(x − 3) − 1(x − 3) = (2x − 1)(x − 3). Option 3 expands to 2x² − 5x + 3, option 4 to 2x² + 5x − 3.

Simplify (x² + 8x + 7) ÷ (x + 1).

  1. x + 7
  2. x + 8
  3. 8x + 7
  4. x² + 8x + 6
Top = (x + 7)(x + 1), so cancel (x + 1) and keep x + 7. Don’t cancel single letters or numbers inside the sum.

Simplify (5 − x) ÷ (x − 5).

  1. 1
  2. −1
  3. 0
  4. x
5 − x = −(x − 5), so the fraction is −1 × (x − 5) ÷ (x − 5) = −1.

Which simplification is correct?

  1. (x + 6) ÷ 6 = x + 1
  2. (3x + 6) ÷ 3 = x + 2
  3. (x² − 9) ÷ (x − 3) = x − 3
  4. (5x + 10) ÷ 5 = x + 10
Factorise first: 3x + 6 = 3(x + 2), so ÷ 3 leaves x + 2. Option 1 cancels the 6 from only one term; option 3 should be x + 3; option 4 forgot to divide the 10 by 5.
