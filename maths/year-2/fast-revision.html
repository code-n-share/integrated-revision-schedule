Only like terms (same letters, same powers) can be added or subtracted. The sign in front belongs to the term.

1.8Inequalities

Solve like an equation, but × or ÷ by a negative → reverse the sign. Then graph in the set asked for.

Example: 4 − 3x > −5, x ∈ ℤ
−3x > −9− 4 each side

🧩 Negative flips the sign: 6 > 4 but −12 < −8.
⚠️ Don't lose marks

  • −4(5a − 2) = −20a + 8: the minus changes every sign inside, not just the first.

🧩 Ch 2 · Factors ⏱ 9 min

1 · Key concepts rule first, then the worked example

2.1Common factor (HCF)

HCF = HCF of the numbers × the letters all terms share. Write it outside, divide each term, expand to check.

Example: 6a²b − 8ab² + 4ab
HCF = 2ab2 · a · b
2ab(3a − 4b + 2)divide each term

2.2Grouping

Four terms: split into pairs, take the HCF out of each, then take out the common bracket.

Example: 3ax − bx − 3ay + by
x(3a − b) − y(3a − b)take out −y
(3a − b)(x − y)common bracket
🧩 “Pair, pull, bracket.”

2.3Difference of two squares

x² − y² = (x + y)(x − y)

HCF first, then square-root each term. Needs a minus.

Example: 12x² − 75y²
3(4x² − 25y²)HCF 3 first
3(2x + 5y)(2x − 5y)(2x)² − (5y)²
51² − 49² = (2)(100) = 200shortcut

2.4Quadratics x² + bx + c

Find two numbers that multiply to c and add to b. c negative → different signs; the bigger one takes b’s sign.

Example: x² − 8x + 15
−3 × −5 = 15, −3 + −5 = −8find the pair
(x − 3)(x − 5)
🧩 Multiply to the end, add to the middle.

2.4Quadratics ax² + bx + c (a > 1)

Work out a × c → find the pair that multiplies to it and adds to b → split the middle term → group.

Example: 3x² + 10x + 8
3 × 8 = 24 → 4 × 6, 4 + 6 = 10a × c
3x² + 4x + 6x + 8split 10x
x(3x + 4) + 2(3x + 4)group
(3x + 4)(x + 2)

2.5Algebraic fractions

Factorise top and bottom, then cancel matching factors (brackets). If everything on top cancels, 1 is left.

Example: 3x² − 5x − 2x − 2
(3x + 1)(x − 2) ÷ (x − 2)factorise top
3x + 1cancel (x − 2)
⚠️ Don't lose marks
  • If a term is the HCF, 1 is left: 3ab + 3a = 3a(b + 1), not 3a(b).
  • x² + 9 is a sum: DOTS doesn't work. Always take out the HCF before DOTS.
  • Cancel factors, never terms: x + 66 ≠ x + 1. And 5 − xx − 5 = −1.

#(A ∪ B) = #A + #B − #(A ∩ B)
Example: 30 pupils, 17 German, 16 Spanish, 5 both. How many do neither?
both = 5overlap first

30 − 28 = 2neither

3.1Number sets & rules

ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ: natural (1, 2, 3 …) · integers (… −1, 0, 1 …) · rational (a/b, b ≠ 0) · real (whole line). 0 ∈ ℤ but 0 ∉ ℕ. For a rule, put each allowed x into the formula.

Example: list C = {2x + 1 | −3 < x < 2, x ∈ ℤ}
x = −2, −1, 0, 1< drops −3 and 2
C = {−3, −1, 1, 3}2x + 1 each

3.2Set difference

A \ B (“A less B”) = in A but not in B. Keep the set before the \. U \ A = A′.

Example: A = {2, 3, 4, 5}, B = {4, 5, 6, 7}
A \ B = {2, 3}remove 4, 5
B \ A = {6, 7}≠ A \ B

3.2–3.3Commutative & associative

Commutative: order doesn't matter (a ∗ b = b ∗ a). Associative: grouping doesn't matter ((a ∗ b) ∗ c = a ∗ (b ∗ c)).

OperationComm.?Assoc.?
+ · × · ∪ · ∩✓ yes✓ yes
− · ÷ · \✗ no✗ no

e.g. (12 ÷ 6) ÷ 2 = 1 but 12 ÷ (6 ÷ 2) = 4 → ÷ not associative. One counter-example is enough to disprove.

3.3–3.4Three-set problems

8 regions. Centre first (call it x if not given) → pairs = pair total − centre → “only” = set total − the rest → outside = U − inside. All regions add to #U.

Example: 86 students, all take ≥ 1 language. F 57, G 42, S 31; F&G 25, F&S 17, G&S 5. All three?
pairs: 25 − x, 17 − x, 5 − xpair − x
only: 15 + x, 12 + x, 9 + xtotal − rest
83 + x = 86all regions = U
x = 3 students
⚠️ Don't lose marks
  • In A ∪ B write each element once; 0 is not in ℕ.
  • A \ B ≠ B \ A: keep the set before the \.
  • Three sets: subtract the centre from each pair total, and don't forget the outside (“none”).

🎲 Ch 9 · Probability ⏱ 9 min

1 · Key concepts rule first, then the worked example

9.1Counting principle

m choices then n choices → m × n outcomes (multiply, never add). To list them, draw a tree or two-way table.

Example: 3 languages, 2 sciences, 2 business subjects, one of each
3 × 2 × 2 = 12 choicesmultiply

9.2Probability scale

0 impossible · ½ even chance · 1 certain. Never below 0 or above 1. 75% = 3 times out of 4 = likely.

🧩 I U E L C: Impossible, Unlikely, Even chance, Likely, Certain (0 → 1).

9.3P(E) for equally likely outcomes

P(E) = favourable ÷ all possible

P(not E) = 1 − P(E). “A or B” → add the favourable outcomes.

Example: one of the 13 tiles P A R A L L E L O G R A M
P(A) = 3/133 As
P(A or L) = (3 + 3)/13 = 6/13

9.4Two events: sample space

Coin + die = 2 × 6 = 12 outcomes · two dice = 36. Draw the grid, circle the matches, divide by the total.

Example: two dice, P(total = 7)
+123456

6/36 = 1/66 cells

9.5Relative & expected frequency

relative freq. = successes ÷ trials
expected freq. = P × trials

More trials → better estimate. All probabilities add to 1.

Example: P(1) = 0.35, P(2) = 0.1, P(3) = 0.25, P(4) = 0.15. Find P(5); 3s in 200 spins?
P(5) = 1 − 0.85 = 0.15add to 1
0.25 × 200 = 50 threesP × trials

9.6Probability from a Venn diagram

P = region ÷ total in U (include the “neither” number). “Or” = everything in both circles, overlap counted once.

Example: club of 130 members (football / tennis)
P(neither) = 45/130 = 9/26
P(F or T) = 85/130 = 17/26

9.7Probability trees

Write the probability on every branch (branches from one point add to 1). Multiply along a path (“and”); add between paths (“or”).

Example: spinner A red 1/4, blue 3/4; spinner B red 3/5, blue 2/5. P(both the same colour)?
red, red = 1/4 × 3/5 = 3/20multiply along
blue, blue = 3/4 × 2/5 = 6/20multiply along
3/20 + 6/20 = 9/20add the two paths
🧩 Along the branches ×, between the branches +.
⚠️ Don't lose marks
  • 3 starters and 4 mains = 3 × 4 = 12 meals, not 7.
  • The bottom of P(E) is all outcomes; for a Venn diagram it's the total in U. The 11 dice totals are not equally likely: use the 36 outcomes.
  • “Exactly one” / “one of each” on a tree has two paths: add them both.

🏁 Final mixed quiz ⏱ 6 min

12 questions, 3 from each chapter. Work each one out before choosing. If you get one wrong, go back to that chapter's concept cards.

Ch 1 · −4(5a − 2) = ?

  1. −20a − 8
  2. −20a + 8
  3. 20a + 8
  4. −20a − 2
−4 × 5a = −20a and −4 × (−2) = +8. The minus changes both signs.

Ch 1 · Solve 5x − 4 = 4x + 7.

  1. x = 3
  2. x = 11
  3. x = −11
  4. x = 7
Subtract 4x from both sides: x − 4 = 7. Add 4: x = 11. (3 comes from 7 − 4: not changing the sign when moving −4 across.)

Ch 1 · Which graph shows x < −2, x ∈ ℝ?

  1. Closed circle at −2, heavy line to the right
  2. Open circle at −2, heavy line to the left
  3. Open circle at −2, dots at −3, −4, −5 …
  4. Closed circle at −2, heavy line to the left
< = open circle (−2 not included); “less than” = to the left; ℝ = a heavy line, not dots.

Ch 2 · What is the HCF of 3xy and 12x²?

  1. 3x
  2. 12x
  3. 3xy
  4. 36x²y
Numbers: HCF of 3 and 12 is 3. Letters both terms share: x (only one has y). So 3x.

Ch 2 · To factorise 6x² + 7x − 5, which pair splits the middle term?

  1. −10 and 3
  2. 6 and −5
  3. 10 and −3
  4. 15 and −2
a × c = −30; the pair must multiply to −30 and add to +7: 10 and −3. Then 6x² + 10x − 3x − 5 = (3x + 5)(2x − 1).

Ch 2 · Which simplification is correct?

  1. (x + 6) ÷ 6 = x + 1
  2. (3x + 6) ÷ 3 = x + 2
  3. (x² − 9) ÷ (x − 3) = x − 3
  4. (5x + 10) ÷ 5 = x + 10
3x + 6 = 3(x + 2), so ÷ 3 leaves x + 2. The first cancels a term, not a factor; the third should be x + 3; the fourth forgot to divide the 10.

Ch 3 · U = {1, 2, … 10}, A = {1, 3, 5, 7}, B = {5, 7, 8, 9}. Find (A ∪ B)′.

  1. {2, 4, 6, 10}
  2. {1, 3, 5, 7, 8, 9}
  3. {2, 4, 6}
  4. {5, 7}
A ∪ B = {1, 3, 5, 7, 8, 9}; the complement is the rest of U: {2, 4, 6, 10}. The second option forgets the complement; the third misses 10.

Ch 3 · 32 pupils all study French or German: 24 French, 18 German. #(F ∩ G) = x. Find x.

  1. 8
  2. 42
  3. 10
  4. 14
24 + 18 − x = 32 → x = 10. (8 = 32 − 24; 42 is just 24 + 18.)

Ch 3 · Which set describes “in A and B but not in C”?

  1. (A ∩ B) \ C
  2. A ∩ B ∩ C
  3. (A ∪ B) \ C
  4. A \ (B ∪ C)
A ∩ B = in both; \ C removes anything in C. A ∩ B ∩ C is the centre; A \ (B ∪ C) is A only.

Ch 9 · Two dice are thrown and the scores added. P(a total of 9)?

  1. 1/36
  2. 1/9
  3. 1/4
  4. 1/11
(3,6), (4,5), (5,4), (6,3): 4 of 36 = 1/9. 1/11 pretends the 11 totals are equally likely.

Ch 9 · 82 houses: 14 only a cat, 12 a cat and a dog, 26 only a dog, 30 neither. P(a cat or a dog)?

  1. 26/41
  2. 32/41
  3. 20/41
  4. 15/41
14 + 12 + 26 = 52 of 82 = 26/41. 32/41 counts the 12 twice; 15/41 is neither.

Ch 9 · Bag A: 2 red, 1 white. Bag B: 1 red, 2 white. One bead from each bag. P(both red)?

  1. 1
  2. 1/3
  3. 4/9
  4. 2/9
Multiply along the branch: 2/3 × 1/3 = 2/9. 1 comes from adding 2/3 + 1/3; 4/9 is P(both the same colour).
