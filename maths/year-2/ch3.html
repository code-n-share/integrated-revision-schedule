🔤 3.1 Revision of Sets Terminology
Equal sets contain exactly the same elements: A = {2, 4, 6, 8} and B = {4, 6, 8, 2} are equal.
💡 A set is a bag of marbles: the order they sit in doesn’t change the bag.

A ∪ B – in A or B

A ∩ B – in A and B

A′ – in U but not in A

IdeaSymbolExample: A = {1, 2, 3, 4}, B = {3, 4, 5, 6}
UnionA ∪ B{1, 2, 3, 4, 5, 6} – write 3 and 4 once only
IntersectionA ∩ B{3, 4}
SubsetB ⊂ AA = {1, 2, 3, 4, 5}, B = {3, 5} → B ⊂ A
ComplementA′U = {1 … 10}, A = {2, 3, 5, 7} → A′ = {1, 4, 6, 8, 9, 10}
Cardinal number#A#A = 4 · #(A ∩ B) = 2 · #(A ∪ B) = 6
🧩 Remember it: ∪ looks like a Union “cup” that holds everything; ∩ is an arch you pass through – only the middle (intersection) gets in.
#(A ∪ B) = #A + #B − #(A ∩ B)

We subtract the overlap because it was counted twice.

➖ 3.2 Set Difference
Set difference: A \ B (“A less B”) is the set of elements of A which are not in B.
💡 Start with A, then cross out anything that is also in B.

A \ B – A only

B \ A – B only

📘 A = {a, b, c, d, e, f, g}, B = {e, f, g, h, i}. Find (i) A \ B (ii) B \ A (iii) (A ∪ B) \ (A ∩ B)
(i) A \ B = {a, b, c, d}remove e, f, g
(ii) B \ A = {h, i}remove e, f, g
A ∪ B = {a, b, c, d, e, f, g, h, i}, A ∩ B = {e, f, g}do the brackets first
(iii) {a, b, c, d, h, i}
Commutative property: an operation is commutative if the order doesn’t matter: 3 + 4 = 4 + 3 and 3 × 4 = 4 × 3. But 6 − 2 ≠ 2 − 6, so subtraction is not commutative.
💡 Putting on socks then shoes ≠ shoes then socks. Some things depend on order; some don’t.

Union and intersection are commutative: A ∪ B = B ∪ A and A ∩ B = B ∩ A. Set difference is not commutative: with A = {2, 3, 4, 5} and B = {4, 5, 6, 7}, A \ B = {2, 3} but B \ A = {6, 7}.

⚠️ Common mistake: writing A \ B when you mean B \ A. The set before the \ is the one you keep. And U \ A is just A′.
🔵 3.3 Venn Diagrams Involving Three Sets
Three overlapping circles in a universal set make eight regions (counting the outside). Each region has its own description.
💡 Every region is a yes/no code: is it in A? in B? in C? The centre is “yes, yes, yes”; the outside is “no, no, no”.
RegionSet notationIn words
1 (centre)A ∩ B ∩ Cin all three
2(A ∩ C) \ Bin A and C but not B
3C \ (A ∪ B)in C only
4(A ∩ B) \ Cin A and B but not C
5A \ (B ∪ C)in A only
6(B ∩ C) \ Ain B and C but not A
7B \ (A ∪ C)in B only
8 (outside)(A ∪ B ∪ C)′in none of the sets
📘 U = {1 … 12}, A = {2, 4, 6, 8, 10}, B = {3, 4, 5, 6}, C = {5, 6, 7, 8}. List (i) A ∩ B ∩ C (ii) (A ∩ B) \ C (iii) B \ (A ∩ B ∩ C)
Place elements: 6 is in A, B and C → centrefind the centre first
(i) A ∩ B ∩ C = {6}
(ii) A ∩ B = {4, 6} → remove C’s 6 → {4}
(iii) B \ {6} = {3, 4, 5}
Associative property: an operation (∗) is associative if (a ∗ b) ∗ c = a ∗ (b ∗ c). For example (2 + 3) + 4 = 2 + (3 + 4), so addition is associative. But (12 ÷ 6) ÷ 2 = 1 and 12 ÷ (6 ÷ 2) = 4, so division is not.

🧩 Remember it: union and intersection behave like + and ×; set difference behaves like − and ÷ (order and grouping matter).

⚠️ Common mistake: “prove” a property with one example. To show a property is not true, one example is enough; to show it is true, compare both sides carefully (or shade a Venn diagram).
🧮 3.4 Solving Problems Using Three Sets
🔧 Method: three-set word problem
  1. Draw three circles in a box. Label A, B, C and give U.
  2. Fill the centre (all three) first. If it isn’t given, call it x.
  3. Pair regions = pair total − centre.
  4. “Only” regions = set total − the centre and its two pair regions.
  5. Outside = U − everything inside. If x is used, add all regions and set equal to U.
📘 100 students: S = sweets (41), D = soft drinks, C = crisps (31). 6 bought all three; 14 crisps & drink; 12 sweets & drink; 15 crisps & sweets; 23 drink only. Find: none, sweets only, two items only, one item only.
All three = 6centre first
C∩D only = 14 − 6 = 8 · S∩D only = 12 − 6 = 6 · C∩S only = 15 − 6 = 9pair − centre
S only = 41 − (6 + 6 + 9) = 20 · C only = 31 − (6 + 8 + 9) = 8total − the rest
None = 100 − (20 + 6 + 23 + 9 + 6 + 8 + 8) = 100 − 80 = 20U − inside
none 20 · sweets only 20 · two only 6 + 9 + 8 = 23 · one only 20 + 23 + 8 = 51
📘 86 students all take at least one language: French 57, German 42, Spanish 31; 25 take French & German, 17 French & Spanish, 5 German & Spanish. How many take all three?
All three = xnot given → let x
F∩G only = 25 − x · F∩S only = 17 − x · G∩S only = 5 − xpair − x
F only = 15 + x · G only = 12 + x · S only = 9 + xtotal − pairs − x
(15 + x) + (12 + x) + (9 + x) + (25 − x) + (17 − x) + (5 − x) + x = 86all regions = U
83 + x = 86the x terms add to +x
x = 3 students
⚠️ Common mistake: forgetting to subtract the centre when a pair total is given, and forgetting the outside region (“none of these”). Check that all eight regions add up to #U.

❓ Quick Quiz

A = {1, 2, 3, 4} and B = {3, 4, 5, 6}. What is A ∪ B?

  1. {3, 4}
  2. {1, 2, 5, 6}
  3. {1, 2, 3, 4, 5, 6}
  4. {1, 2, 3, 3, 4, 4, 5, 6}
Union = everything in A or B. Write each element once, so 3 and 4 appear once. {3, 4} is the intersection; {1, 2, 5, 6} is what is in only one set.

A = {1, 3, 5, 7} and B = {5, 7, 8, 9}. What is A ∩ B?

  1. {1, 3, 5, 7, 8, 9}
  2. {5, 7}
  3. {1, 3, 8, 9}
  4. {5, 7, 8, 9}
Intersection = only the elements in both sets: 5 and 7. The first option is the union; the third is what is in only one set.

U = {1, 2, … 10}, A = {1, 3, 5, 7} and B = {5, 7, 8, 9}. Find (A ∪ B)′.

  1. {2, 4, 6, 10}
  2. {1, 3, 5, 7, 8, 9}
  3. {2, 4, 6}
  4. {5, 7}
A ∪ B = {1, 3, 5, 7, 8, 9}. The complement is everything in U that is not in it: {2, 4, 6, 10}. The second option forgets the complement; the third misses 10.

#A = 15, #B = 14 and #(A ∩ B) = 7. Find #(A ∪ B).

  1. 29
  2. 22
  3. 36
  4. 7
#(A ∪ B) = 15 + 14 − 7 = 22. 29 forgets to subtract the overlap; 36 adds it instead.

List B = {2x | −3 < x < 4, x ∈ ℤ}.

  1. {−2, −1, 0, 1, 2, 3}
  2. {−4, −2, 0, 2, 4, 6}
  3. {−6, −4, −2, 0, 2, 4, 6, 8}
  4. {−4, −2, 0, 2, 4, 6, 8}
x = −2, −1, 0, 1, 2, 3 (the strict < drops −3 and 4). Double each: −4 … 6. Option 1 forgot to double; options 3 and 4 included an end value.

Which set equals ℚ ∩ (ℕ ∪ ℤ)?

  1. ℕ
  2. ℤ
  3. ℚ
  4. ℝ
ℕ ∪ ℤ = ℤ (ℕ sits inside ℤ). Then ℚ ∩ ℤ = ℤ, because every integer is a rational number.

32 pupils all study French (F) or German (G): 24 French, 18 German. #(F ∩ G) = x. Find x.

  1. 8
  2. 42
  3. 10
  4. 14
24 + 18 − x = 32 → 42 − x = 32 → x = 10. (8 = 32 − 24; 42 is just 24 + 18; 14 = 32 − 18.)

A = {1, 2, 3, 4, 5, 6, 7, 8} and B = {3, 6, 9, 10}. What is A \ B?

  1. {9, 10}
  2. {3, 6}
  3. {1, 2, 4, 5, 7, 8}
  4. {1, 2, 4, 5, 7, 8, 9, 10}
A \ B = elements of A that are not in B: remove 3 and 6. {9, 10} is B \ A; {3, 6} is A ∩ B; the last one is both differences together.

A = {1, 2, 3, 4, 5} and B = {3, 5}, so B ⊂ A. What is A ∩ B?

  1. A
  2. B
  3. { } (empty)
  4. A \ B
If B ⊂ A, everything in B is already in A, so the overlap is all of B: A ∩ B = B (and A ∪ B = A).

Which set describes “in A and B but not in C”?

  1. (A ∩ B) \ C
  2. A ∩ B ∩ C
  3. (A ∪ B) \ C
  4. A \ (B ∪ C)
A ∩ B = in both; then \ C removes anything in C. A ∩ B ∩ C is the centre; (A ∪ B) \ C includes things in only A or only B; A \ (B ∪ C) is A only.

What do you fill in first when solving a three-set problem?

  1. The centre, A ∩ B ∩ C
  2. The “only” regions
  3. The region outside the circles
  4. The total of each circle
The centre is part of every pair and every circle total. Start there, subtract it to get the pair regions, then the “only” regions, and last the outside.

Which set is the same as U \ A?

  1. A′
  2. A \ U
  3. A ∩ U
  4. A ∪ U
U \ A = everything in U that is not in A, which is the complement A′. A \ U is empty (nothing in A is outside U); A ∩ U = A; A ∪ U = U.
